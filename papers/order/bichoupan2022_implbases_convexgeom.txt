                                                Abstract. A convex geometry is finite zero-closed closure system that sat-
                                                isfies the anti-exchange property. Complexity results are given for two open
                                                problems related to representations of convex geometries using implication
                                                bases. In particular, the problem of optimizing an implication basis for a
                                                convex geometry is shown to be NP-hard by establishing a reduction from
                                                the minimum cardinality generator problem for general closure systems.
                                                Furthermore, even the problem of deciding whether an implication basis
                                                defines a convex geometry is shown to be co-NP-complete by a reduction
                                                from the Boolean tautology problem.


                                                                          1. Introduction
                                            Convex geometries are finite zero-closed closure systems satisfying the anti-
                                         exchange property. P. Edelman and R. Jamison introduced convex geometries
                                         in [6] as a common formulation for various equivalent structures appearing
                                         in several areas of research, including lattice theory and relational databases.
                                         More recently, K. Adaricheva and J.B. Nation published a survey of work
                                         related to convex geometries [2]. H. Yoshikawa et al. found a notable ap-
                                         plication for convex geometries in computer-driven education systems, where
                                         convex geometries are used in their dual form as antimatroids to model the
                                         space of possible knowledge states of learners [13].
                                            This paper continues an effort to study convex geometries through the lens
                                         of implication bases.
                                            A set of implications Σ = {Ai → Bi : 1 ≤ i ≤ n} defining a finite closure
                                         system is an optimum basis if its size is minimal among all implication bases
                                         for the same closure system; the size of an implication basis is the sum of all
                                         cardinalities of the sets on the left and right sides of its implications. D. Maier
                                         showed that the general problem of finding an optimum basis for a closure
                                         system given by an arbitrary implication basis is NP-hard [9].
                                            On the other hand, several special classes of closure systems are known to
                                         have tractable optimum bases. M. Wild showed tractability of optimum bases
                                         for modular closure systems in [12], and E. Boros et al. showed tractability

of optimum bases for component-quadratic closure systems in [4]. In partic-
ular, many subclasses of the convex geometries are known to have tractable
optimum bases. K. Kashiwabara and M. Nakamura proved tractability of op-
timum bases for affine geometries [8], and K. Adaricheva showed tractability
of optimum bases for convex geometries that satisfy the Carousel property,
convex geometries that do not have D-cycles, and convex geometries of order
convex subsets in a poset [1]. But the problem of determining whether there
is a tractable algorithm to find optimum bases of convex geometries in general
has remained open.
   We show that, given an arbitrary implication basis for a convex geometry,
the problem of finding an optimum basis is NP-hard. The proof relies on a
reduction from the minimum cardinality generator problem for general closure
systems, described in Section 3. In [10], C.L. Lucchesi and S.L. Osborn de-
scribe a problem equivalent to the minimum cardinality generator problem and
prove NP-completeness by a reduction from the graph vertex cover problem.
Section 3 gives a proof of the intractability of the minimum cardinality gen-
erator problem by a reduction from the Boolean CNF satisfiability problem.
Section 4 completes the proof of intractability of optimum bases of convex
geometries.
   In Section 5, we show that even the problem of deciding whether an im-
plication basis defines a convex geometry is co-NP-complete. The proof is a
direct reduction from the Boolean DNF tautology problem.

              2. Definitions and Background Theorems
   We use definitions and notational conventions from [3, 5]. A closure system
hX, φi is a set, X, equipped with a function, φ : P(X) 7→ P(X), satisfying the
properties A ⊆ φ(A), A ⊆ B =⇒ φ(A) ⊆ φ(B), and φ(φ(A)) = φ(A) for all
A, B ⊆ X; such a function φ is called a closure operator on X, and the sets
in the image of φ are called closed sets. Closure systems can be equivalently
defined in terms of their closed sets: if F is a family of subsets of X such that
F is closed under set intersection and F contains X, the function φ defined
by φ(A) = ∩{S ∈ F : A ⊆ S} for all A ⊆ X is a closure operator on X, and
the image of φ is precisely F . Conversely, if hX, φi is a closure system and F
is the image of φ, then F is closed under set intersection, F contains X, and
φ(A) = ∩{S ∈ F : A ⊆ S} for all A ⊆ X. A closure system hX, φi is finite if
its ground set, X, is finite. A closure system hX, φi is zero-closed if the empty
set is closed in the system, i.e. if φ(∅) = ∅.

   A convex geometry is a finite zero-closed closure system satisfying the anti-
exchange property. For a finite closure system hX, φi, the anti-exchange prop-
erty is the condition that y 6∈ φ(A ∪ {x}) or x 6∈ φ(A ∪ {y}) for every closed

set A ( X and all x, y ∈ X \ A with x 6= y. A condition equivalent to the
anti-exchange property for finite closure systems hX, φi is that for every closed
set A ( X, there is an element x ∈ X \ A such that A ∪ {x} is closed.

   An implication on a nonempty set X is an ordered pair of sets A, B ⊆ X
where B 6= ∅, denoted A → B. An implication A → B on X holds in the
closure system hX, φi if, for every closed set S of hX, φi, A ⊆ S =⇒ B ⊆ S,
or equivalently if B ⊆ φ(A). For any set Σ of implications on a set X, the
family of sets F = {S ⊆ X : ∀(A → B) ∈ Σ: A ⊆ S =⇒ B ⊆ S} is closed
under set intersection and contains X, and Σ is called an implication basis
for the closure system on X associated with F . Given an implication basis Σ
of a finite closure system hX, φi and a set S ⊆ X, there are straightforward
algorithms to compute φ(S).

   A quasi-closed set Q of a closure system hX, φi is a subset of X such that Q
is not closed and for every closed set S of hX, φi, Q ⊆ S or S ∩ Q is closed; an
equivalent definition is that Q ⊆ X is quasi-closed if Q is not closed and for all
S ⊆ Q, φ(S) = φ(Q) or φ(S) ( Q. A critical set C of a closure system hX, φi
is a quasi-closed set that is minimal among all quasi-closed sets of hX, φi that
have the same closure as C; that is, a quasi-closed set C is critical if for every
quasi-closed set Q ( C, φ(Q) ( φ(C). If hX, φi is a closure system, F is the
family of all closed sets of hX, φi, and Q is the family of all quasi-closed sets of
hX, φi, then the family of sets F ∪ Q is closed under set intersection and has
an associated closure system, hX, σi, where σ is called the saturation operator
of hX, φi.

Theorem 1. If hX, φi is a finite closure system, σ is the associated saturation
operator, and Σ is an associated implication basis, then for every critical set
C of hX, φi, there is an implication (A → B) ∈ Σ such that σ(A) = C.
Furthermore, for every finite closure system hX, φi, the set ΣC = {C → φ(C) :
C is a critical set of hX, φi}, called the canonical basis of hX, φi, is a valid
implication basis of hX, φi and has minimal cardinality among all implication
bases of hX, φi.

  J.L. Guigues and V. Duquenne proved the statements of Theorem 1 in [7],
and D. Maier gave a similar result in the context of relational databases [9].
M. Wild later connected Guigues and Duquenne’s work to Maier’s and made
their results significantly more accessible in [11].

  An implication basis ΣO of a finite closure system hX, φi is called an opti-
mum basis of hX, φi if the sum of all cardinalities of all left and right sides of
the implications in ΣO is minimal among all implication bases for hX, φi. It

   The Boolean satisfiability problem gives a Boolean proposition, P , on n
variables and asks if there exists a truth assignment, ψ, of the variables such
that P evaluates to true according to ψ. The Boolean CNF satisfiability prob-
lem is a special case of the Boolean satisfiability problem that only considers
propositions written in conjunctive normal form. A Boolean proposition is
in conjunctive normal form if it is expressed as a conjunction of clauses, and
each clause is a disjunction of literals; a literal is either a single variable or
the complement of a single variable. The Boolean CNF satisfiability problem
is equivalent to the Boolean satisfiability problem in the sense that both are
NP-complete.

   The Boolean tautology problem is a dual problem to the Boolean satisfiability
problem: the Boolean tautology problem gives a proposition, P , on n variables
and asks if there is a truth assignment, ψ, of the variables such that P evaluates
to false according to ψ. The Boolean DNF tautology problem is a special case
of the Boolean tautology problem that only considers propositions written in
disjunctive normal form; a Boolean proposition is in disjunctive normal form
if it is expressed as a disjunction of clauses, and each clause is a conjunction
of literals. The Boolean DNF tautology problem is dual to the Boolean CNF
satisfyability problem, and both the Boolean DNF tautology problem and the
general Boolean tautology problem are co-NP-complete.

         3. The Minimum Cardinality Generator Problem
   A generator of a closure system hX, φi is a set S such that φ(S) = X. Given
a set of implications Σ, the minimum cardinality generator problem asks to
find a generator of minimal cardinality for the closure system associated with
Σ. In [10], C.L. Lucchesi and S.L. Osborn studied an equivalent problem
phrased in the language of functional dependencies for relational databases,
and proved a result equivalent to Lemma 2 below.
Lemma 2. The minimum cardinality generator problem is NP-hard.
Proof. The proof proceeds by reduction from the Boolean CNF satisfiability
problem. Let P be a Boolean expression on n variables, a1 , ..., an , and suppose
that P is written in conjunctive normal form with clauses c1 , ..., cm ; that is,
P = c1 ∧ ... ∧ cm , where each cj is a disjunction of literals.

   Let X = {x1 , ..., xn , y1, ..., yn , z1 , ...zm , s}, and define the set of implications
Σ as follows:
      • For each clause cj of P and each literal ai in cj , (xi → zj ) ∈ Σ.
      • For each clause cj P and each literal ¬ai in cj , (yi → zj ) ∈ Σ.
      • (z1 ...zm → s) ∈ Σ.
      • For each i, (sxi → yi ) ∈ Σ and (syi → xi ) ∈ Σ.
Any generator of the closure system associated with Σ must contain xi or yi
for each i, and therefore must have cardinality at least n. On the other hand,
the closure system associated with Σ has a generator of cardinality n if and
only P is satisfiable.
   Given a truth assignment ψ of (a1 , ..., an ), let S ⊆ {x1 , ..., xn , y1 , ..., yn } be
the set of cardinality n such that xi ∈ S if (and only if) ai is true according to
ψ and yi ∈ S if (and only if) ai is false according to ψ. Then zj ∈ φ(S) if and
only if cj evaluates to true under ψ, and s ∈ φ(S) if and only if P evaluates
to true under ψ. It follows that φ(S) = X if and only if P evaluates to true
under ψ.                                                                                  

      5. Deciding if a Closure System is a Convex Geometry
Theorem 4. Given an arbitrary implication basis, the problem of determining
whether the closure system associated with that basis is a convex geometry is
co-NP-complete.
Proof. Inclusion in co-NP is clear, because it is easy to validate a counterex-
ample to the anti-exchange property when an implication basis is given (and
it is easy to determine if the associated closure system is zero-closed).
   The proof of co-NP-hardness proceeds by reduction from the Boolean DNF
tautology problem. Let P be a Boolean expression on n ≥ 2 variables,
a1 , ..., an , and suppose that P is written in disjunctive normal form. Let
   COMPLEXITY RESULTS FOR IMPLICATION BASES OF CONVEX GEOMETRIES                             7

c1 , ..., cm be the clauses of P ; so P = c1 ∨ ... ∨ cm , where each cj is a con-
junction of literals.
    Let X = {x1 , ..., xn , t1 , ..., tn , f1 , ..., fn }. Let xn+1 = x1 . Define an implica-
tion basis Σ on X as follows:
         • For each positive integer i ≤ n, (xi ti → xi+1 ) ∈ Σ and (xi fi → xi+1 ) ∈
           Σ.
         • For each cj , define the set Sj ⊆ {t1 , ..., tn , f1 , ..., fn } as follows: ti ∈ Sj
           if (and only if) cj contains the literal ai , and fi ∈ Sj if (and only if) cj
           contains the literal ¬ai . For all Sj , (Sj → x1 ) ∈ Σ.
The closure system associated with Σ is a convex geometry if and only if P is
a tautology.
    If P is not a tautology, then there is truth assignment, ψ, of the ai such
that P is false under ψ. Define A ⊆ {t1 , ..., tn , f1 , ..., fn } such that ti ∈ A if
(and only if) ai is true according to ψ and fi ∈ A if (and only if) ai is false
according to ψ. Since P is false under ψ, all of its clauses are false under ψ as
well. It follows that no implication in Σ has a left hand side that is a subset
of A, so A is closed. But then the closure system associated with Σ fails the
anti-exchange property, since, for any i, the closure of A ∪ {xi } contains all of
{x1 , ..., xn }.
    Now suppose that P is a tautology. It remains to show that for every closed
set C other than the top element, there is an e ∈ X \ C such that C ∪ {e} is
closed. Let A be a closed set such that for every i, ti ∈ A or fi ∈ A. Then there
is some implication (S → x1 ) ∈ Σ with S ⊆ A, so in fact {x1 , ..., xn } ⊆ A.
Then A ∪ {e} is closed for all e ∈ X \ A. Let B be a closed set such that for
some i, ti 6∈ B and fi 6∈ B. Then there are three cases:
         • If xi 6∈ B, then B ∪ {xi } is closed.
         • If there is j ≤ n with xj+1 ∈ B and xj 6∈ B, then B ∪ {xj } is closed.
         • If {x1 , ..., xn } ⊆ B, then, as before, B ∪ {e} is closed for all e ∈ X \ B.
