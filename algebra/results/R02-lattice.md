# R ∩ W is a complete lattice

**Status: PROVED**

Intersections of dual-Horn model classes are dual-Horn, so `R ∩ W` is
union-closed, contains ∅ and E, and is therefore a **complete lattice with
join = union**.

Measured confirmation: 0 union violations in 175,230 pairs.
**Meet is not intersection**: 51,917 violations.
