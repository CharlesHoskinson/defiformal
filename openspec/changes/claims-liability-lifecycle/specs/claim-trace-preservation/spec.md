## Purpose

Defines the bounded fixed-claim lifecycle contract described in design.md.

## ADDED Requirements

### Requirement: CT01 Preserve actual ordered cursor observations

The cursor SHALL retain full world/capability/claim state, actual events/receipts/outputs, absolute index and exact failure; every successful command increments index and a failed suffix is inert.

#### Scenario: T01 Metadata and payment commands share a sequence

- **WHEN** metadata and payment commands share a sequence
- **THEN** metadata consumes an absolute index without inventing outputs; payment uses the actual prior output history.

#### Scenario: T02 A command refuses after a successful prefix

- **WHEN** a command refuses after a successful prefix
- **THEN** only located failure is added and every subsequent command is skipped.

#### Scenario: T03 ContinueRun is split at an arbitrary entry cursor

- **WHEN** continueRun is split at an arbitrary entry cursor
- **THEN** append equality preserves the whole cursor without reinitialization.

### Requirement: CT02 Prove authorized no-disappearance

Reachability SHALL be generated by actual command equations and SHALL prove row presence, immutable fields, status transitions, other-row framing and authorized accounting changes.

#### Scenario: T04 A reachable existing liability decreases

- **WHEN** a reachable existing liability decreases
- **THEN** an actual debtor payment or creditor forgiveness accounts for exactly that decrease.

#### Scenario: T05 Default, transfer, extension or legacy execution occurs

- **WHEN** default, transfer, extension or legacy execution occurs
- **THEN** remaining/paid/waived stay unchanged and every other row remains exact.

#### Scenario: T06 A trace starts with empty claims and creates loans

- **WHEN** a trace starts with empty claims and creates loans
- **THEN** every appended row has an actual funding-event witness, not merely an assumed well-formed row.

### Requirement: CT03 Prove conservative projection at the right scope

Legacy-only programs embedded with empty claims SHALL project exactly to existing Composition continuation; mixed lifecycle traces SHALL retain their distinct indexing and failure semantics.

#### Scenario: T07 An arbitrary legacy cursor including prior failure is embedded

- **WHEN** an arbitrary legacy cursor including prior failure is embedded
- **THEN** legacy continuation preserves its exact old events, history, world, index and failure.

#### Scenario: T08 A mixed lifecycle trace is projected

- **WHEN** a mixed lifecycle trace is projected
- **THEN** only proved local world/payment/stutter facts are claimed; metadata indices and paymentMismatch are not silently erased.
