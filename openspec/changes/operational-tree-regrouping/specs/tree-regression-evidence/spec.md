The implementation SHALL cover all twenty explicit fixture contracts, enumerate90 nonduplicate complete(2,2,2) schedules and12 funded causal schedules, and construct expected observations independently of candidate runners, labeling synthetic/arbitrary-entry versus actual financial cases.

#### Scenario: S39 Synthetic scope

#### Scenario: S42 Inherited controls refreshed
