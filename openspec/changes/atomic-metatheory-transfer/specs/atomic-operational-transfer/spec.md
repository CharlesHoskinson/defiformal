## Purpose

Transfers exact execution and settlement observations through binary and actual tree representations inside one unchanged Atomic boundary.

## ADDED Requirements

### Requirement: FT01 Exact binary correspondence

The finite specialization SHALL correspond to accepted Atomic admission, arbitrary-entry continuation, finish and public results with complete fields and diagnostics.

#### Scenario: T01 The finite roster is left/right with identical inputs

- **WHEN** the finite roster is left/right with identical inputs
- **THEN** the converted full machine/result equals the actual accepted binary Atomic execution.

#### Scenario: T02 Binary schedule counts differ on both branches

- **WHEN** binary schedule counts differ on both branches
- **THEN** conversion retains both expected/observed counts using the original streams and schedule, not only a first mismatch.

### Requirement: FT02 Actual tree settlement simulation

Tree regrouping SHALL keep outer identity, entry, ordered policy, monitor, roster and schedule fixed and SHALL prove each actual attempted receipt and settlement update correspond.

#### Scenario: T03 Valid distinct tree shapes route the same fixed schedule

- **WHEN** valid distinct tree shapes route the same fixed schedule
- **THEN** all speculative prefixes, outstanding entries, positions, aborts and final public observations correspond.

#### Scenario: T04 A subtree finishes early or resets the entry/owed state

- **WHEN** a subtree finishes early or resets the entry/owed state
- **THEN** the nonempty transient fixture distinguishes the result and the candidate violates the one-boundary contract.

### Requirement: FT03 No boundary or schedule reassociation inference

The theorem SHALL exclude moved commit boundaries and different-schedule first-abort equality, with concrete negative companions.

#### Scenario: T05 Transfer7 then refused6 is split into separate Atomic events

- **WHEN** transfer7 then refused6 is split into separate Atomic events
- **THEN** one outer event rolls back to10/0/0, whereas two boundaries retain3/7/0.

#### Scenario: T06 An inner finish is inserted between draw7 and return7

- **WHEN** an inner finish is inserted between draw7 and return7
- **THEN** the early residual7 abort differs from the clearing whole event.

#### Scenario: T07 Two disjoint refusing streams are scheduled in different orders

- **WHEN** two disjoint refusing streams are scheduled in different orders
- **THEN** the first abort identity/position can differ despite equal rollback balances.
