## Why

Accepted Sprint9 preserves execution when referenced configuration declarations agree. It does not prove preservation of old behavior when new participants actually execute. M5 supplies that separate projection theorem and a restricted contextual-substitution rule.

This is a provisional author draft. Accepted S10/M3/M4 delivery, exact API refresh and same-candidate nonauthor GPT-6/native Fable planning review are prerequisites to official freeze and implementation.

## What Changes

- Restrict an extended schedule to old participant identities, retaining their order and static slot counts.
- Project actual execution onto protected ledger cells, the full capability store, old local observations and filtered old attempts, preserving exact receipts, histories and refusals.
- Prove prefix simulation using actual old-step dependency congruence and new-step write frames; allow added peers to read protected state and to refuse in ordinary interleaving.
- Prove congruence for a declared invocation-only continuation/peer context grammar, with explicit support, boundary, configuration and store premises.
- Add independent financial fixtures, omitted-field comparisons, negative companions and actual runtime mutations; preserve administration and Atomic boundaries as separate dependencies.

## Capabilities

### New Capabilities

- `active-extension-projection`: Stable roster/schedule restriction and complete protected observations.
- `active-extension-preservation`: Initialized actual-prefix simulation and supported ledger preservation.
- `restricted-active-contexts`: Precisely admitted continuation and peer contexts with contextual substitution.
- `active-extension-evidence`: Independent financial oracles, mutations, inherited controls and frozen review bindings.

### Modified Capabilities

None. S9 configuration/group equivalence and the proposed M3/M4 contracts are dependencies, not rewritten requirements.

Proposed new runtime modules under `lean/DefiKernel/Extension/`: `Projection`, `Isolation`, `ContextSyntax`, `Examples`, `Tests`, `Audit`.
