## ADDED Requirements

### Requirement: Independent finite and raw observations
Evidence SHALL implement the twenty named fixture families, independent complete raw observations and explicit premise/counterexample categories. Existing cursorEq alone SHALL NOT stand in for past raw event world comparisons.

#### Scenario: E01 Complete actual execution tables
- **GIVEN** each applicable F01–F20 fixture
- **WHEN** run
- **THEN** independent expected data compare all finite ledger cells, full store, raw event before/post worlds, step/index/receipt/outputs, history, nextIndex and exact located failure.

#### Scenario: E02 Synthetic observer scope
- **GIVEN** F17 field-difference pairs
- **WHEN** comparison sensitivity is reported
- **THEN** they are classified as synthetic observer tests and not executed unauthorized financial behavior.

#### Scenario: E03 Premise and counterexample inventory
- **GIVEN** the theorem/fixture map
- **WHEN** reviewed
- **THEN** generic proofs, finite instances, counterexamples and explicitly unchecked assumptions remain separate with no vacuous successful denominator.

### Requirement: Fourteen query and observer mutations
The fourteen planned production mutations SHALL exercise actual new provenance/current-authority queries or selected-view comparisons with exact source edits. Reports SHALL explicitly retain this scope and SHALL NOT relabel them as mutation coverage of historical authority guards.

#### Scenario: E04 Compiling intended detection
- **GIVEN** each exact frozen M01–M14 edit
- **WHEN** the full production comparison inventory runs
- **THEN** it compiles, the designated comparison becomes false and the funded-peer positive stays true.

#### Scenario: E05 Overlap and siblings
- **GIVEN** mutation output
- **WHEN** summarized
- **THEN** every false label and a relevant valid sibling are retained; sensitivity is not unique fault identification.

#### Scenario: E06 Blocked is not detected
- **GIVEN** a compile, capture, timeout or protocol failure
- **WHEN** classified
- **THEN** exit3 is blocked and the exact failed attempt is preserved without a semantic-detection claim.

### Requirement: Frozen sources and actual defensive controls
Evidence SHALL bind actual frozen source/spec/tool bytes, full raw logs and applicable timings, and run all65 inherited defensive CLI cases plus required legacy regressions. No official mutation/control execution SHALL precede the authorized source freeze.

#### Scenario: E07 Exact runtime closure
- **GIVEN** a production freeze
- **WHEN** projection is built
- **THEN** all local imports are captured, only the new namespace proof suffix is stripped, runtime definitions and imported old proofs remain, and source/spec/driver Git and byte bindings agree.

#### Scenario: E08 Inherited controls
- **GIVEN** the documented literal adaptation
- **WHEN** all65 actual CLI cases execute
- **THEN** the inherited expected classifications and production numeric #eval failure protocol are retained with correct log paths.

#### Scenario: E09 Mutation input drift or invalid inventory
- **GIVEN** drift, empty/duplicate/incomplete inventories, ambiguous edits or unsafe output paths
- **WHEN** the real runner is invoked
- **THEN** it blocks with exit3 while valid sibling controls remain valid.

### Requirement: Independent planning and delivery gate
This package SHALL have its own planning, source/evidence and verified-delivery gates. Author preparation, strict OpenSpec validation, research acceptance and unrelated package review SHALL NOT count as implementation or proof acceptance.

#### Scenario: E10 Planning gate
- **GIVEN** this author draft and exact source applicability
- **WHEN** frozen
- **THEN** nonauthor GPT-6 and native Fable5.1 medium must substantively accept the same bound inputs before implementation.

#### Scenario: E11 Implementation and evidence review
- **GIVEN** a completed implementation candidate
- **WHEN** native Grok and Fable reviews run
- **THEN** actual model identity, raw result, source hashes and remediation are retained; unavailable or tool-only output is no verdict.

#### Scenario: E12 Final status and preserved history
- **GIVEN** accepted source/evidence and verified delivery
- **WHEN** final claims are updated
- **THEN** original maps/attempts and explicit later gaps remain, and only evidenced tasks are checked complete.
