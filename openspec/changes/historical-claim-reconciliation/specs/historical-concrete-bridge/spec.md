## Purpose

Binds exact historical unary-rule data to universal finite-instance Lean theorems while preserving all source and runtime trust boundaries.

## ADDED Requirements

### Requirement: HB01 Bind complete fixed-instance data

The bridge SHALL encode every vocabulary item and extraction decision for both source-bound instances and SHALL reject missing, ambiguous, swapped or drifted data.

#### Scenario: B01 The fixed LSTAR and PARSED_NEW data are extracted

- **WHEN** the fixed LSTAR and PARSED_NEW data are extracted
- **THEN** the ordered 58-name bijection, complete source rows and 13/12 versus 16/15 occurrence/distinct-edge inventories are separately reconciled.

#### Scenario: B02 One edge, vocabulary item, external flag or instance label changes

- **WHEN** one edge, vocabulary item, external flag or instance label changes
- **THEN** the binding fails despite an unchanged headline cardinality, and the unchanged sibling passes.

### Requirement: HB02 Prove universal saturation correspondence

The bridge SHALL prove finite executable unary saturation equals reflexive-transitive reachability for every input, including empty and full sets, without assuming the desired equality or relying on sampled executions.

#### Scenario: B03 Arbitrary finite input S is supplied

- **WHEN** arbitrary finite input S is supplied
- **THEN** the universal theorem proves the same encoded closure as reachability using finite stabilization and least-closed-superset reasoning.

#### Scenario: B04 A purported proof covers only nonempty size-at-most-three seeds or defines closure directly as reachability

- **WHEN** a purported proof covers only nonempty size-at-most-three seeds or defines closure directly as reachability
- **THEN** that evidence is insufficient for correspondence of the independently defined saturation executor.

### Requirement: HB03 Establish concrete graph hypotheses

The bridge SHALL prove the reachability antisymmetry premise for each exact graph and SHALL disclose self-loop normalization and direction conventions.

#### Scenario: B05 A topological rank is supplied for the actual graph

- **WHEN** a topological rank is supplied for the actual graph
- **THEN** every non-self edge is checked and a path argument establishes reflexive-transitive antisymmetry; self-loop removal preserves closure.

#### Scenario: B06 A two-cycle or reversed edge violates the claimed certificate

- **WHEN** a two-cycle or reversed edge violates the claimed certificate
- **THEN** the checked hypothesis rejects it or a precise counterexample is proved; a compiler setup failure is not counted as that negative.

### Requirement: HB04 Instantiate intrinsic extreme-point results

The bridge SHALL instantiate the unchanged generic results with intrinsic deletion-based extreme points, explicit reachability orientation, and all closed-input premises where required.

#### Scenario: B07 Extreme points and their composition are reported

- **WHEN** extreme points and their composition are reported
- **THEN** the proof relates the intrinsic definition to the paper-oriented maximal predicate and supplies actual same-instance anti-exchange, generator and composition theorems.

#### Scenario: B08 Extreme points are merely defined as maximal elements or closed-input premises are omitted

- **WHEN** extreme points are merely defined as maximal elements or closed-input premises are omitted
- **THEN** the proposed correspondence claim is rejected and the correctly scoped theorem remains accepted.

### Requirement: HB05 State source translation and language boundaries

The bridge SHALL separately identify fixed-source extraction validation, universal Lean instance proof, reviewed algorithm translation, and bounded JavaScript execution.

#### Scenario: B09 The local m5 loop is mapped to the Lean executor

- **WHEN** the local m5 loop is mapped to the Lean executor
- **THEN** initialization, insertion, least-fixed-point and termination arguments explain traversal-order differences without claiming a verified Node or parser implementation.

#### Scenario: B10 The UI depth-limited helper, full admissibility predicate or arbitrary future parser input is substituted

- **WHEN** the UI depth-limited helper, full admissibility predicate or arbitrary future parser input is substituted
- **THEN** the instance applicability is rejected or left open; no broader paper conclusion follows from matching names.
