Signed typed receipt effect. `receiptEffect` (`Policy.lean:72–75`) is `e.effect cell` on an invoked receipt and 0 otherwise. `Evaluated.effect` sums every evaluated delta at that cell, including repeats. `updateOutstanding` subtracts that amount only for `(lane ∈ policy.lanes ∧ p = principal)` using `(boundaries attempt.branch attempt.index).ctx.principal` (`Execution.lean:113–114`). `step_receipt_balance` (`Settlement.lean:29–39`) ties the applied post-balance to that same `receiptEffect` via `applyEvaluated_ok_iff`.
