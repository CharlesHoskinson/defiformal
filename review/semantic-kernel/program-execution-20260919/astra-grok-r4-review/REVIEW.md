2. **21.2 analyzes synthetic branches and the wrong boundaries.** `splitInvokeBranches` partitions component id zero versus every other id; it does not decode a declared branch pair. `invokeSteps` silently omits issue/revoke. `checkRun` then analyzes every invocation under `boundaries 0`, whereas execution uses boundaries at each original step index. `analyzeInvocation` resolves actor-relative references and access using this boundary, so the discrepancy matters to actual footprints. The repeated-component-zero probe and empty-invocation probe both return true against an empty branch. Those observations are not by themselves counterexamples to the underlying Parallel theorem: they demonstrate that this adapter does not establish the intended declared-payload meaning or nontrivial negative gate. Declare that meaning, preserve original boundary/index correspondence, explicitly handle noninvoke semantics, and supply nonempty success/refusal witnesses.
3. **Trusted-host checks are incomplete and can be empty.** Missing host JSON passes `verify_trusted_host` with dependency count zero. Required dependency inventory and metadata are not checked, nor are the JSON records compared to compiled `TrustedHost`. The production `recordsMatch` call is confined to the unused library helper. A compiled probe shows `checkTyped` accepts an otherwise intact certificate with wrong toolchain, mathlib revision and compiler record while git remains unchanged. Missing/empty/omitted records, altered source pins, grammar/schema changes and compiled-host drift need actual fail-closed controls.
4. **Successful codec and scenario evidence is missing.** D7 independently justifies rejecting unsorted F13/F28; F53 correctly retains its earlier `unsupportedForm.treeJoin` failure. But F13/F28 were the only successful codec cases, so all 16 codec cases now reject and no independent successful structural expectedIR is compared. The old F13 IR placeholder is a prose string, and F28 IR is null; neither was repaired into a positive structural oracle. Add new named canonical positive companions without rewriting historical raw bytes. A changed-IR comparator control must fail. Reconcile all 99 scenario evidence classes: S14 explicitly requires successful F13 decoding but is called verified on malformed output; S13 requires a canonical/permuted pair; S80 requires actual isolated `package.py --check` empty/intact CLI executions, which F01 decode does not provide. 5. **Actual-domain execution correspondence remains open.** The author correctly identifies this; it is not a newly discovered hidden theorem failure. Finish 21.1 while preserving the accepted codec theorem and admission domain before qualified delivery.
6. **Working-tree provenance has misleading Git fields.** `--bind-working-tree` captures and checks actual SHA256 bytes and detects later drift. However, `matches_git_head` records only whether `git rev-parse` found a path, not equality of the committed blob and captured bytes; `binding_scope` still says they equal HEAD objects.
