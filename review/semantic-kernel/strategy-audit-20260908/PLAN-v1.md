**Goal:** Establish reusable semantic, library, adapter and verification interfaces whose value is demonstrated across distinct financial behaviors before broadening the portfolio.
**Architecture:** Retain the delivered Lean execution/composition kernel. Put reusable financial functions and contracts above it; connect pinned implementations through explicit adapters/refinements. A narrow serialized checker calls the same supported Lean semantics and reports assumptions separately. Versioned source/proof/evaluation evidence supports these interfaces.
**Current decision:** Keep the core approach, change sequencing and progress accounting. No sampled delivered theorem defect demands a mathematical restart. Source correspondence and demonstrated reuse remain decisive unknowns.

7. **Freeze and evaluate.** Freeze relevant API/schema/library versions before selecting untouched cases; audit exposure separately. Compare schema/behavioral coverage, library reuse, new concepts, external assumptions and verification effort. Final paper and scientific Atlas reflect accepted measured/proved scope only.

## Falsification criteria

- If source/model relation requires the desired postcondition or excludes ordinary supported behavior, revise the boundary before extending libraries.
- If accounting/nonnegative state is the entire claimed economic result, restate the guarantee and select a substantive financial predicate.
- If the second operation forces a separate executor/harness or repeats the full global proof, simplify the proposed reusable interfaces before adding more operators.
- If a mutant compiles but does not change its designated observation, repair the oracle/case; compilation failure and timeout are blocked evidence, not detection.
- If local generic premises cannot be inhabited and discharged on actual successful/refused traces, stop that instance rather than adding more theorem-count evidence.
- No new author lane starts merely because a slot is free: it needs a stable input contract and a real independent checker/delivery path.
