## Graph limits and cost

Graphify extraction was deterministic with **0 model input/output extraction tokens**; the five human-language agent reviews have separate inference cost, not measured as graph-extraction tokens. No token-reduction benchmark or savings claim is made. Native Graphify AST handles supported languages; Lean uses literal imports with nested comments/strings masked. Unsupported languages are inventory only. Static resolution misses dynamic/CLI/shell consumers; candidate→primary import fallback is navigation, not compiled dependency equality. Full corpus/holdout documents and review payloads were not ingested. The interactive HTML uses its Graphify CDN dependency.

Structural hubs include legacy reporting dependencies. Community cohesion and graph size are not financial coverage, proof-quality or dead-code metrics. The graph provides concrete counterexamples to orphan deletion: standalone Axioms and unfinished Claims Preservation are roots despite no incoming imports.
