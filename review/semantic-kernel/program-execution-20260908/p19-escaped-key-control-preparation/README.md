# Escaped-key repair controls

The successful attempt3 exercises all32 C0 characters using two distinct source-map keys per character: `k` plus the character, and its literal `ku00xx` spelling. Every pair is sorted; every encoded witness is3455 bytes, depth6, and maximum array length32. The old lexical scanner and production decoder reject every pair as duplicate, while the canonical parser plus object decoder succeeds.

Two genuine-duplicate JSON controls preserve the distinction between scanner and parser: a repeated literal key is refused by both; an equivalent Unicode-escaped key passes the old scanner but is refused by the parser. Distinct quote and backslash key controls pass both stages. These are bounded runtime controls, not a kernel proof of full admissibility or universal roundtrip.

The probe uses sealed R14 private build state. Encode and Decode are byte-identical to frozen R15; the CanonicalJson definition prefix is also identical. It does not access live AGY or Grok source/build state. Initial launcher and reserved-identifier failures are preserved separately with zero success credit. Only attempt3 has a successful complete compiler receipt. The controls await use against the frozen scanner repair and independent review.
