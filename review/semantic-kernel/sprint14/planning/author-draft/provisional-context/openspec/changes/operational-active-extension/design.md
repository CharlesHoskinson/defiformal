## Goals / Non-Goals

Prove preservation of old execution observations while additional invocation-only participants execute in the same ledger universe. New participants can change unprotected balances, read old state, produce outputs, mint outside the protected region, and refuse. Their refusal stops their own stream in ordinary interleaving, never all participants.

No unrestricted old/new world equality, symmetric peer independence, arbitrary context closure, mutable configuration, issue/revoke, extra capability entries, identity renaming, atomic boundary transfer, financial solvency, deployed fidelity or full abstraction is claimed. Arbitrary M3 causal-monitor state is not part of the projection: a monitor counting all attempts changes on a new peer step. Preserving such a monitor would need a separate factorization through the protected projection and stuttering-invariance proof, which this change does not supply. No new financial executor replaces M3. This draft implements nothing.

## Decisions

### D1. Identities and actual schedule restriction

Keep the same finite ledger types P/A/D and their equality instances. Participant IDs U are separate from authenticated principals. The extended roster enumerates U exactly once. A finite selected set K defines old IDs as subtype `{u : U // u ∈ K}`; the old roster is the stable filter of the extended roster with proof tags. Old streams and boundaries are exactly restricted along the inclusion. Empty K and K=all are meaningful limiting cases; they cannot be the only positive fixtures.

Define `restrictSchedule K : List U → List OldId` by order-preserving filter-and-retag, not by sorting, deduplicating or mapping new IDs to a default old ID. Prove erasure identity, membership/order preservation, append compatibility and, for each old u, equality of its token count before/after restriction. Then extended completeness implies completeness for restricted old streams, including slots skipped after refusal. This does not say an arbitrary prefix is complete or that a new peer token increments an old consumed counter.

The compared old invocation stream and absolute-index boundary function agree at every old ID and relevant successful index, including principal, environment and time. Boundaries remain fixed functions of stream/local index; no replacement by global extended schedule position is permitted. Proposed global attempt records have no independent clock; if accepted M3 adds one, the refresh must specify a justified projected index or block this theorem.

### D2. The protected observation is a new type

Use a finite `S : Finset (Cell P A D)` and a `ProtectedWorld` containing balances restricted to S and the entire capability store. Do not manufacture a full State by zeroing omitted cells, and do not apply S9 `CursorEquivalent` to partial-world equality. The latter deliberately requires every ledger cell equal.

A projected event retains its old local index, exact Step/invocation, exact evaluated receipt including ordered deltas/reads/writes/supply, exact outputs and both before/result worlds projected to S. A projected attempt retains old participant identity, local index, invocation, protected before world and exact error or successful protected result/receipt/outputs. Project the extended attempt list by filtering old IDs in actual chronological order; delete only new attempts. Preserve order among old attempts and do not confuse skipped slots with attempts.

A projected local state retains consumed, nextIndex, exact located failure including invocation/reason/index, the entire own output history and all projected events. `projectMachine K S` contains the current protected world, projected locals in stable old-roster order and filtered projected attempts. The old machine uses the same projection onto S without participant deletion. The optional result projection also retains the restricted supplied schedule and result kind. It does not erase catalog/structural admission failures or relabel an extended admission failure as a matching old failure.

Old output histories and receipts are literally equal, not filtered by port/asset/domain. Only balances in raw embedded worlds and the histories/attempts of new IDs are omitted. New receipts may change global total supply; project old supply as the sum of actual filtered old successful attempts, not the extended aggregate. Preserve every asset/domain field of those old receipts. Prove the finite Boolean comparator true iff equality of this exact observation. Synthetic single-field comparator tests are supplemental to actual financial executions.

### D3. One-way isolation and configuration support

Require both catalogs valid and S9 `ConfigAgreement oldCfg newCfg refs` for every old call/operation reference used by the complete old streams and admitted contexts. This includes referenced registry templates, component/operation lookup results and **all-domain** administrator equality. Shared type instances and equal boundaries are explicit; equality only at one currently used administrator is not the stated premise. New peers execute under newCfg. Fixed declaration extension is not store extension.

Analyze all complete streams with their actual boundary indices, even financially unreachable suffixes. Prove analysis invariance for old branches from supported references and ConfigAgreement; no execution equality premise substitutes for this result. Every old analyzed read, write and output snapshot cell lies in S. Every new analyzed write avoids S. All compared initial stores are exactly equal, including entries, live/revoked flags and allocation length. Both old and new Nary streams are invocation-only, so actual execution preserves that store. Peers can use grants already present in the same initial store; a grant added only to the extended initial store violates this premise.

The runtime `checkIsolation` checks finite footprint containment and exclusion in deterministic old/new roster order using actual analyzer lists. It reports the first old read/write outside S or new write in S with ID/cell. It is not a configuration-equivalence, authority or general invariant certificate. Configuration support/equality and initialization remain independently checked/proved premises. The real M3 admission remains authoritative and can reject a malformed added declaration/branch before replay even if the old run would succeed. The preservation theorem is conditional on successful extended admission; no theorem promises admission after arbitrary declarations are added.

This is strictly one-way: new reads may overlap old writes. Existing symmetric Parallel compatibility is a sufficient stronger special case, but cannot be imposed and advertised as the general theorem. A peer reading an old balance while writing elsewhere is a required positive witness for this distinction.

### D4. Noncircular prefix simulation

Define `Related K S` by exact protected observations of the old/extended machines. At genesis, initial protected balances and full store agree, and all old locals/attempts are empty. For arbitrary populated entries, require the full projected local/attempt equality plus explicit static-slot alignment: every enabled selection in either machine (failure=none and branches[u][consumed]?=some invocation), including new peers, has nextIndex=consumed so full-branch analysis at the static slot covers its actual boundary; exhausted overscheduled streams need no such equality because no invocation can execute; selected old streams have the same invocation at consumed and equal nextIndex/history, while failed streams retain their failures. Reuse accepted M3 reachability/local-order only for entries that actually arise from those executions. Do not assume arbitrary synthetic cursors are reachable.

Prove two step lemmas from actual dispatcher equations:

- Old token: configuration congruence plus `executeStep_congr` relates the actual two invocations. Success preserves S, exact receipts/outputs and old histories; refusal yields the same exact reason/location with no event or nextIndex advance; skip increments only selected consumed. Unselected old locals stay equal. Projected before/post worlds in appended events and attempts agree.
- New token: actual success changes no balance in S by its analyzed write frame and leaves the fixed store/old locals untouched. Refusal/skip likewise preserve them; any new event/attempt disappears only in projection. This is stuttering of the old projection, not identity of the extended state or evidence that the peer succeeded.

Induct on the actual extended token prefix t to prove

`projectMachine K S (extended.runPrefix t) = projectOld S (old.runPrefix (restrictSchedule K t))`.

For related valid populated entries prove the corresponding continuation equation, including arbitrary overlong token lists and failed suffix slots. The old/new static branch data and boundary support must cover those entries as stated above. Derive projected start, append/chunking and complete-result corollaries. Derive restricted old admission from successful extended admission, ConfigAgreement, full old analysis correspondence and count restriction; retain catalog-before-branch-before-count precedence from actual M3. No desired whole-run equality or peer success is assumed.

For any ledger predicate I supported on S (`AgreeOn S x y → (I x ↔ I y)`), old I after each restricted prefix implies extended I at that prefix. When claiming an invariant, separately supply an initialized old preservation theorem. This transport is not automatic discovery of support or preservation. A global total over unprotected cells is not supported merely because old operations never write those cells.

### D5. Restricted contexts and the stronger interleaving premise

Use an invocation-only syntax and its actual executors, not arbitrary functions that can inspect or replace machines. A restricted sequential continuation has `.hole`, `.before fixed context`, `.after context fixed`, with fixed invocation-only groups, equal configuration/boundaries and analyzed support contained in S at every relevant absolute position. Its semantics continues the full supplied cursor; it never reconstructs/reset history, nextIndex or failure from the observation. Define a protected cursor relation with the same world/event projection and exact histories/failure/index. Prove invocation step and recursive-group preservation using dependency congruence. Define protected group equivalence over **every pair of related input cursors**, with support hypotheses at the possible input index; equality from a single funded start is insufficient. Prove context congruence for these constructors. S9's full-world equivalence remains a separate stronger relation with different admissible admin contexts.

An active-peer context consists of fixed added invocation streams, roster inclusion and an order-preserving schedule embedding whose restriction is the specified old schedule. It runs actual M3 continuation. It may insert peer slots before, between or after old slots, provided D3 isolation and all other premises hold. For substitution inside such an interleaving, require old programs related at **every corresponding old token prefix**, with the same old static slot counts and selection/index convention. Endpoint group equality alone does not provide this premise: Composition cursors do not record the number of static suffix slots after an unconditional refusal, while Nary consumed counters do. A one-invocation always-refusing group and that group with a never-executed suffix can have equal sequential cursors but different branch lengths. Balance-only endpoint equality is weaker still and does not equate receipts or intermediate observations. This relation is between old-only executions; the proof of the extension theorem derives preservation in the added peer context, rather than assuming it. Prove matching old-token/peer-token cases and compose before/after segments using the actual continuation theorem.

No arbitrary context function, raw-world inspection outside S, merged peer history, old capability modification, schedule-dependent boundary rebinding or transaction-wide abort constructor belongs to this grammar. Contexts cannot use omitted diagnostic data to choose future old invocations. Fixed old branch code can read only analyzed cells in S and its own exact history. New peer programs may observe S, but their effects remain outside it.

Transport the result through accepted M4's actual full fixed-schedule tree simulation and stable roster conversion; do not define a tree theorem by flattening a tree and assuming runtime equivalence. A concrete regrouping substitution must use the actual accepted tree representation proof for every prefix. M4's reduced equality across different schedules cannot replace fixed-schedule simulation, since this projection retains chronological old attempts and embedded protected worlds. No arbitrary schedule permutation law is introduced.

## Risks / Trade-offs

- Protected equality can omit a real dependency → include every old analyzed read/write/snapshot and retain a snapshot-only counterexample.
- A peer failure can be mistaken for transaction failure → actual interleaving success/refusal/skip fixtures plus an explicitly excluded Atomic companion.
- Endpoint equality can be inflated into contextual equivalence → universal related-entry sequential premise and stronger all-old-prefix relation for inserted peer slots.
- New grants can silently alter old behavior → exact complete-store equality and separate fresh-ID/revocation negatives; dynamic provenance remains future work.
- Future APIs can drift → accepted-predecessor refresh is a blocking planning prerequisite, with retained observed provisional snapshots.
