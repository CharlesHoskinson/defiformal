# v0.1.0 source research release

These notes describe the v0.1.0 source research release. Use the corresponding
Git tag and GitHub release to identify its exact source revision and publication
record. Preparation started from delivery revision
`6ebed6bf2af7bb753ab26085cc934cfc5dfd321a` on `semantic-kernel-pivot` in the
[delivery repository](https://github.com/stefan-contiu/defiformal).

## Included source

- Lean models and proofs for typed financial operations, capabilities, accounting
  and frame preservation, sequential workflows, parallel execution, shared-state
  interleaving and atomic settlement. Each theorem retains its stated premises.
- Checked integer arithmetic and the existing source-bound certificate work,
  with their individual [acceptance records](../../review/semantic-kernel/).
- [Pinned IOG benchmark adapter sources](../../benchmarks/competitive-landscape/README.md)
  and a portable replay wrapper. The 13 abstract workloads retain their separate
  adapted-library or new-model classifications and original provenance.
- A [pinned CI workflow](../../.github/workflows/lean.yml) that builds the declared
  default targets, runs a fresh imported-kernel axiom audit and executes the
  existing audit success/rejection controls. An empty audit cannot pass.
- [Apache-2.0 license text](../../LICENSE), [scoped retained notices](../../THIRD_PARTY_NOTICES.md)
  and a [contribution guide](../../CONTRIBUTING.md).

## Reproduce the source build

Use Git and Lean's `elan` toolchain manager. The repository pins Lean
`4.33.0-rc2` and mathlib revision `51e6992efd06126df61a496bebf8f49482a4e129`.
From a checkout of the release source:

```sh
cd lean
lake exe cache get
lake build
```

The cache supplies compiled dependencies. These commands do not claim a full
rebuild of every imported dependency. See the [README examples](../../README.md#run-an-example)
and the adapter guide for focused execution and proof replay.

## Limits and open work

This is a research source release. It does not complete the
[37-sprint roadmap](../../openspec/ROADMAP.md), establish deployed-contract or
bytecode equivalence, or provide unconditional solvency or liveness guarantees.
Trusted callers, registries, administrators, oracles and initial states remain
explicit model inputs. Proof, bounded execution, mutation checks and measurement
retain their separate evidence scopes.

No outside actor has completed a recorded reproduction of this release. The
external reproduction/onboarding gate remains open. Benchmark source availability
and focused internal replay do not establish a complete benchmark campaign,
performance ranking or independent kernel implementation. Individual accepted
records retain their exact revisions, tools, reviewers and limitations.

The Apache-2.0 grant covers the authorized original code/proofs and selected
adapter inventory. Historical third-party evidence keeps its own terms; consult
the [retained notices](../../THIRD_PARTY_NOTICES.md) before reusing those copies.
