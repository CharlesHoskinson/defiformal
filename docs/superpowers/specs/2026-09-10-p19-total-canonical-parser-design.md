# P19 total canonical parser design

The required result is the production theorem `decodeBytes (encodeModule ir) = .ok ir` for every supported canonical IR in the accepted finite grammar. R6 made expression decoding total and added component lemmas, but it did not prove this theorem. The pinned Lean JSON parser still uses partial recursive string, number, array, object and value routines. The captured source is in `review/semantic-kernel/program-execution-20260908/p19-proof-r6-root-inspection/`.

This is an implementation decision within the already-authorized P19/P20 roadmap and accepted certificate grammar. Historical planning bytes remain unchanged. The user assigns native AGY Gemini3.8 Flash High to implementation and native Grok4.6 to independent review; root records the design and verifies the result. Existing autonomous authorization covers this routine architectural repair. No new user approval or expanded product scope is claimed.

Two approaches can supply accessible kernel equations. A total implementation of the complete upstream JSON parser would also cover number forms the certificate lexical layer rejects. A total parser for the certificate's integer-JSON language can preserve the accepted certificate behavior with fewer parser cases to prove. Use the latter unless implementation evidence shows that the former provides a simpler verified dependency. Both must preserve the same public grammar and refusal classifications.

Add a total parser module under `lean/DefiKernel/Certificates/`, with explicit decreasing input or fuel and sufficient-bound proofs. Its interface is `parseCanonicalJson : ByteArray → Except DecodeFailure Lean.Json`. Keep schema/IR decoding separate. The production `decodeBytes` must consume the new parser, retain the lexical/resource checks and canonical re-encoding admission condition, and preserve supported audit/codec behavior even though the universal IR theorem covers execution IR.

Prove string/UTF-8, integer/rational, array and object serialization inverses, then recursive expression and all nonempty container/world/envelope inverses. Any declarative IR-to-Json helper used in those proofs must be connected to the actual encoder and decoder. An alternate codec, cached encoder image or desired-result premise cannot discharge the target.

Structural admissibility must express the accepted normal forms and resource bounds, including complete32-cell worlds, nested rationals, inactive value fields, identifiers, ordering, whole-document depth, array lengths and serialized size. Local expression depth alone is insufficient. Prove sufficient fuel and serialization bounds from those structural conditions. Preserve ordinary nonempty transfer, guard, argument and sequential cases; do not reduce the domain to easy examples.

Validation checks exact positive and refusal behavior, control-character and Unicode escaping, nonempty nested structures, resource boundaries and the actual theorem's axioms. Continue to the universal theorem and fresh independent review. The separate overlay, decoded-IR equality and trusted host/compiler repairs remain required before full P19 acceptance. All new evidence must use a fresh attempt directory; R6's accidental writes to R5 were preserved and restored separately.
