## Non-degeneracy

The basis is non-degenerate if no sort collapses and no primitive is pure
renaming of another. Load-bearing checks from BASIS:

1. `Q ≠ Σ` — Post may write Σ, never Q (no-forgery)
2. `T ≠ Q` — time only advances monotonically; never transferred as balance
3. `Φ ≠ N` — phases written; names fixed index sets
4. `B` only from Cmp

## Sufficiency

Every corpus action is a guard (`Cmp` term) plus simultaneous assignment of
`Led`/`Prop`/`Post` terms. Generation rate on the honest ten (2.3): **~16.6%
ungenerated protocol definitions** — so P is **not** sufficient for the
measured corpus slice. Sufficiency fails as a universal claim; residual is
coverage (2.2) and missing generators (N-families, mandate).
